# Webshop Foundation

Foundation documentation for the premium editorial peptide webshop in `projek-12/premium-peptide-webshop`.

## Status
- Phase 1 repository audit: complete (the audited repository snapshot contained only `README.md` with the heading `# webshop`).
- Phase 2 foundation: in progress. ADR-001 was approved by the project owner on 24 November 2026; remaining items are tracked in `tasks/phase-2-foundation.md`.
- Phase 3 design system: specification drafted in `docs/design/DESIGN-SYSTEM.md`; awaiting owner review.
- Phase 4 homepage and later phases: not started.
- No website source code is included in this repository yet.

## Repository identity
This documentation set belongs to `projek-12/premium-peptide-webshop`. Earlier drafts named the target repository as `ikap2420-blip/webshop`; that name has been replaced throughout. The Phase 1 audit result itself is unchanged.

## How to use
1. Work on a feature branch of `projek-12/premium-peptide-webshop`; do not commit directly to `main`.
2. Read `docs/adr/ADR-001-proposed-architecture.md`. It is approved (24 November 2026); the file name is kept for link stability.
3. Ask Claude Code to read `CLAUDE.md`, `DEVELOPMENT_ROADMAP.md`, `docs/`, and `tasks/` before implementing anything.
4. Update `docs/PROGRESS.md` as work is completed.

Do not overwrite existing files without inspecting and reconciling them first.
