# Phase 3 — Design system

## Goal
Define and review the visual system before building page layouts.

## Tasks
- [ ] Confirm palette and contrast.
- [ ] Select properly licensed display and interface fonts.
- [ ] Define type scale, spacing scale, container widths, grid, and breakpoints.
- [ ] Define buttons, links, navigation, product cards, badges/status labels, and form controls.
- [ ] Specify responsive behavior for mobile, tablet, and desktop.
- [ ] Specify reduced-motion and keyboard/focus behavior.
- [ ] Create a small visual reference sheet or component preview.
- [ ] Update design documentation and progress.

## Acceptance criteria
- Light theme only.
- Components are accessible and responsive.
- Design is product-led, not an agency portfolio.
- No unlicensed fonts or copied third-party assets.
