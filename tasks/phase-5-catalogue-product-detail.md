# Phase 5 — Shop and product detail

## Goal
Build a factual, filterable catalogue and product detail template.

## Tasks
- [ ] Define typed product schema and provenance fields.
- [ ] Add only owner-supplied or properly sourced product data.
- [ ] Build category/filter UI with keyboard support.
- [ ] Build product detail sections for verified specifications and documentation.
- [ ] Show verification status and missing-document states honestly.
- [ ] Add metadata and structured data only for substantiated facts.

## Acceptance criteria
- Demo content is unmistakably demo content.
- No dosing, treatment, reconstitution, injection, or self-administration content.
- No invented purity, blend ratios, COAs, certificates, or approvals.
- Product availability does not imply legal sale eligibility.
