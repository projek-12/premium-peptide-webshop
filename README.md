# Webshop Foundation

Foundation documentation for the premium editorial peptide webshop.

## Status
- Phase 1 repository audit: complete (the supplied repository snapshot contained only `README.md`).
- Phase 2 foundation: proposed; review ADR-001 before implementation.

## How to use
1. Unzip this bundle into the root of the existing `ikap2420-blip/webshop` repository on a feature branch.
2. Review `docs/adr/ADR-001-proposed-architecture.md` and either approve or amend it.
3. Ask Claude Code to read `CLAUDE.md`, `DEVELOPMENT_ROADMAP.md`, `docs/`, and `tasks/` before implementing anything.
4. Update `docs/PROGRESS.md` as work is completed.

Do not overwrite existing files without inspecting and reconciling them first.
